# План функционального тестирования GreenSwap

## Объекты проверки

1. Загрузка страницы и отображение карточек.
2. Фильтрация по типу растения.
3. Отображение владельца и статуса предложения.
4. Адаптивность интерфейса на узком экране.

## Критерий завершения

Все критические сценарии выполнены, дефекты уровня blocker отсутствуют.
