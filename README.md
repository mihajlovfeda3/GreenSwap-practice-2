# GreenSwap

Учебный прототип веб-приложения для локального обмена растениями, семенами и черенками.

## Возможности прототипа

- просмотр карточек растений;
- фильтрация предложений по типу растения;
- отображение статуса доступности;
- подготовка данных и тестовых материалов в отдельных ветвях.

Проект создан для практической работы по Git и GitHub.
